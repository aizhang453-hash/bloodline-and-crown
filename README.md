# 血脉与王冠

一个致敬《十字军之王》(Crusader Kings) 系列的中世纪家族策略游戏。**第一阶段做完了 (v1.0): 能从头玩到尾 —— 地图和时间、人物、家族和继承 (国王会老会死, 由继承人接着玩)、结婚生子、封臣、打仗、阴谋、随机事件和决议。议会、宫廷、宗教这些还没有。**

作者的另外两个游戏: [《废土之旅》](https://github.com/aizhang453-hash/wasteland-trail) (致敬《俄勒冈之旅》的中文文字冒险游戏)、
[《最后的废土》](https://github.com/aizhang453-hash/the-last-wasteland) (致敬《辐射》一二代的角色扮演游戏)。

## 打算怎么做

- 你扮演一个家族的家长: 管领地、结婚生子、跟手下的贵族打交道、打仗、搞阴谋。你的角色会变老、会死, 死了由继承人接着玩, 一代一代传下去
- **867 年的不列颠群岛** (英格兰、苏格兰、威尔士、爱尔兰): 维京大军刚登陆英格兰, 岛上有很多大大小小的王国。以后再一个国家一个国家往外加地图
- 开局的国王和贵族是真实的历史人物, 后来出生的人随机生成
- 有一张能点的地图, 时间会自己往前走, 可以暂停、调快慢
- 用 [Godot](https://godotengine.org/) 游戏引擎做 (免费、开源), 先做电脑版
- 一块一块做, 每做完一块都能试玩。第一个能从头玩到尾的版本有: 地图和时间、人物、家族和继承、结婚生子、封臣、打仗、阴谋、随机事件和决议

## 现在能玩什么

- 867 年 1 月 1 日的不列颠群岛: 130 块领地、26 个国家, 开局的国王是真实的历史人物 (史料里查不到的 3 个地方随机生成, 名字也用当时当地的)
- 在地图上点一块领地, 左边弹出这块领地的窗口 (谁的、属于哪个公国和王国、挨着谁), 再点「玩这个人」选这块地的主人来玩: 国王, 或者封臣 (郡长、小国王……)
- 空格让时间走起来, 有五档速度; 能换地图模式 (国家、公国、王国、帝国、家族)
- 地图上分得清谁管哪块地: 同一个国家里不同主人的地之间有深色的线, 放大了每个主人的地上有他的纹章 (国王的带王冠);
  选中一个人, 他直辖的地亮起来, 别处暗下去
- 每个人有一张自己用代码画的**像素头像** (照当时当地的发型、胡子、头巾、衣服; 年纪大了头发变白), 史料里讲到长相的照着画 (比如「扁鼻子凯蒂尔」)
- 每个人有**性格** (36 种)、教育、天生的特点、六种本事 (外交、军事、管理、密谋、学识、武力)、健康、压力, 还有对别人的好感。
  真实国王的性格照史料给 (比如威塞克斯的埃塞尔雷德一世「虔信」「勇敢」)
- **家族和继承**: 史料里有记载的家人都在 (比如威塞克斯国王的弟弟阿尔弗雷德、罗德里大王的七个儿子)。人会老、会死,
  按当地的习惯继承: 盎格鲁-撒克逊人「长者继承」、威尔士人和诺斯人「平分继承」(儿子们分家)、盖尔人「推举继承」。你的国王死了, 接着玩继承人
- **结婚生子**: 给家里的人说亲 (看对方肯不肯, 不满 16 岁先订婚), 两个国王家的人结婚两国就结盟。夫妻会生孩子, 长相和天生的特点会遗传;
  孩子 3 岁有小时候的性格, 6 岁起跟老师学, 16 岁定下教育和性格。近亲结婚照 867 年教会的规矩 (七代以内不行), 爱尔兰照当地古法可以有不止一个妻子。
  史料里 867 年以后的婚事会照着发生 (比如 868 年阿尔弗雷德娶埃尔斯维斯), 史料里有名字的孩子用真名 (阿尔弗雷德的长子爱德华、卡德尔的儿子「好人」休厄尔……)
- **封臣**: 国王自己管几块地 (有上限), 别的分给封臣。叫法照当时当地: 英格兰的「郡长」、爱尔兰的「小国王」、维京人的「雅尔」,
  史料里有记载的用真名 (伯克郡郡长埃塞尔伍尔夫、布雷加国王弗兰·麦克·科奈英……)。每块领地每月出钱出兵, 封臣按合同交一部分;
  可以把领地封给家里人或者本地贵族、把公国封给家里人当副王、收回领地、关大牢、送礼; 做不正当的事涨「暴政」, 封臣都不高兴
- 点左下角的头像打开**人物窗口**; 鼠标指着本事、健康、好感, 会列出每一项加了多少
- **打仗**: 宣战要有理由 (宣称、法理、维京人征服、圣战、封臣独立) 和威望; 征兵、在地图上带着军队走 (隔海坐船)、两军相遇就打、
  停下来围城, 被占的地画斜条纹; 战争分数到了能逼对方答应, 也能平局、投降、花钱求和; 盟友会来帮忙。
  开局维京大军就在跟诺森布里亚打, 以后历史上的几场仗 (维京大军打麦西亚、东盎格利亚、威塞克斯……) 电脑到时候照着宣战, 输赢看真打
- **阴谋**: 暗杀 (拉对方身边的人当内应, 攒机会、怕走漏)、拉拢; 知道了别人的秘密可以揭发或者勒索, 拿到把柄能逼他答应婚事、交出领地
- **决议**: 控制了一大半的地就能建立公国、王国 (苏格兰、爱尔兰……)、不列颠帝国, 别人拿着就篡夺过来;
  当地特别的决议: 维京人划出丹麦法区、建立群岛王国、斯特拉斯克莱德扩成坎布里亚王国
- **随机事件**: 平均一年一件 (孩子打架、封臣来借钱、吟游诗人、歉收、打猎落马……), 选一个办法; 照史料来的事件 (878 年的日食、891 年的彗星、
  抬着圣卡斯伯特棺材流浪的修士……) 右上角有「历史背景」
- **压力**: 做违背性格的事、家里人去世压力会涨, 涨多了会崩溃: 染上酗酒、写日记这些排解压力的毛病, 严重的会疯掉、让位, 甚至寻死
- **存档**: 随时能存档、读档, 每年自动存一次
- **提醒**: 屏幕上方正中的小图标提醒你该办的事 (孩子没有老师、家里有人该结婚了、自己管的领地太多、大牢里关着人), 点一下直接去办
- **开局设置**: 开局前可以选 生成家人 (给史料里没有家人的贵族配上妻子和儿子)、铁人模式 (只能自动存档, 不能读档反悔)、孩子夭折多少、历史上的婚事和孩子、历史上的仗和阴谋照不照着来
- 界面照《十字军之王》三代的摆法: 右上角是钱和威望, 右边一列按钮, 左下角是你的头像和纹章, 右下角是日期和速度。图标都是自己画的欧洲中世纪小图。还没做的按钮点了会提示「以后才有」

## 怎么玩

要先装好 [Godot 4.7](https://godotengine.org/download) (免费)。然后二选一:

- 打开 Godot, 点「导入」, 选游戏文件夹里的 `project.godot`, 再点右上角的 ▶ (或者按 F5)
- 或者在 Mac 的终端里输入 (Windows 上把前面换成 Godot 程序的位置):

```
/Applications/Godot.app/Contents/MacOS/Godot --path ~/game/bloodline-and-crown
```

操作: 鼠标点领地看详情; 点头像看人物 (人物窗口下面有「说亲」「教育」「互动」按钮, 宣战在「互动」里); 右边一列第一个按钮看你的领地和封臣, 第二个是军队 (征兵), 第五个是阴谋; 左下角最右边的圆按钮是决议; 事件弹窗点一个办法或者按数字键; 点自己的军队选中, 右键点一块地让它走过去; 拖动或者 W A S D 移动地图; 滚轮放大缩小 (放大了能看到每块领地的名字);
空格暂停 / 继续; + - 或者 1～5 换速度; 右下角「≡」存档、读档; 开局前横幅下面的「开局设置」; Esc 关窗口; F1 看操作说明。

## 说明

这是致敬, 不是照搬: 游戏里不会用《十字军之王》的名字、图片和音乐。地名和历史人物是真实的历史。

这不是开源项目, 许可证不允许自己修改代码 (见下面的「许可证」)。

## 用到的别人的东西

- 海岸线: [Natural Earth](https://www.naturalearthdata.com/) 的 1:1000 万陆地数据, 是公共领域 (谁都能免费用)。
  `tools/make_map.py` 用它切出不列颠群岛, 做成 `data/generated/` 里的领地图。
- 867 年的国王是谁、他们的家人、开局的郡长和小国王、867 年以后的婚事和孩子的名字、867–872 年的几场仗和 872 年的暗杀, 查的是维基百科上的历史资料。
